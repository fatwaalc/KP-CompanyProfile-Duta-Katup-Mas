This project is a modern and responsive **Company Profile Website** developed for **PT. Duta Katup Mas**, a valve service specialist based in Balikpapan. The website is designed to showcase the company's technical capabilities, services, and facilities in the Oil & Gas and Power plant industries.

---

## 🛠️ Tech Stack

Built with a modern development workflow for optimal performance:

* **Framework:** [Vue.js 3](https://vuejs.org/) (Composition API)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
* **Routing:** [Vue Router 4](https://router.vuejs.org/)
* **Icons:** [Lucide Vue Next](https://lucide.dev/)

---

## 🚀 Key Features

* **Responsive Multi-Page Design:** Seamless navigation across Home, About, Services, and Products.
* **Service Highlights:** Detailed technical information for Valve Repair, Actuator Maintenance, PSV, and Instrumentation.
* **Interactive Components:** Modular UI with carousels for equipment and facilities documentation.
* **Optimized Performance:** Fast loading speeds through Vite and component-based architecture.

## ⚙️ Installation & Usage

### Prerequisites
* Node.js (v18 or newer)
* npm (v9 or newer)

### Steps
1.  **Clone the repository:**
    ```bash
    git clone https://github.com/fatwaalc/KP-CompanyProfile-Duta-Katup-Mas.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd KP-CompanyProfile-Duta-Katup-Mas
    ```
3.  **Install dependencies:**
    ```bash
    npm install
    ```
4.  **Run development server:**
    ```bash
    npm run dev
    ```
5.  **Build for production:**
    ```bash
    npm run build
    ```
